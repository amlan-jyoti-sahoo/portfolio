React Web for React Native Developers

Since you already have 3 years of experience with React Native, picking up React.js for the web is going to be incredibly easy for you, as 90% of the concepts are exactly the same!

1 The Core is 100% Identical

The react package is exactly the same one used in React Native. This means everything you know about logic and state management directly translates:

  • Hooks (useState, useEffect, useMemo) are identical.
  • Props, Component Lifecycles, and Context API behave the exact same way.

2 The Render Engine: <View> vs <div>

React Native translates primitive components into native iOS/Android UI elements. On the web, we use HTML tags.

React Native React JS (Web) Purpose
<View> <div> Container for layout.
<Text> <h1>, <p>, <span> Displaying text and headings.
<TouchableOpacity> <button>, <a> Requires onClick not onPress.
<Image> <img> Requires src instead of source.

3 Styling: StyleSheet vs Tailwind CSS

In React Native, you use StyleSheet.create(). In your web project, we are using Tailwind CSS.

React Native (StyleSheet)

<View style={{ 
  flexDirection: 'row', 
  margin: 16 
}}>
  <Text>Hello</Text>
</View>

React Web (Tailwind)

<div className="flex flex-row m-4">
  <p>Hello</p>
</div>

Deep Dive: How Tailwind translates React Native concepts

1. The Spacing Scale (Margins & Padding)

In React Native, you use exact pixels (marginTop: 16). Tailwind uses a 4-pixel scale. m- is margin, p- is padding.

  • mb-2 = marginBottom: 8px (2 * 4)
  • px-4 = padding on the X-axis (left/right) of 16px
  • mt-10 = marginTop: 40px

2. Flexbox (It defaults to ROW!)

CRITICAL: In React Native, default flexDirection is 'column'. On the web, if you add the flex class, the default direction is ROW.

  • flex = turns on flexbox (default row)
  • flex-col = flexDirection: 'column'
  • items-center = alignItems: 'center'
  • justify-center = justifyContent: 'center'

3. Responsive Modifiers (md:, lg:)

Mobile apps have fixed screen sizes. The web stretches! You can change styles based on window size using prefixes:

className="text-2xl md:text-3xl lg:text-5xl"

This means: Default to text-2xl, but if the screen is Medium (Tablet) switch to text-3xl, and if Large (Desktop), jump to text-5xl.

Industry Standards to Learn Next

As a React Native dev, you already know state and components. Here is what you should learn to become a Senior React Web Developer.

1. Routing: React Router DOM

In React Native, you use React Navigation. On the web, URLs are everything. You need to learn React Router DOM, which is the industry standard for mapping URLs (like /about or /dashboard) to specific React Components.

<Route path="/about" element={<About />} />

2. Data Fetching: TanStack Query (React Query)

While you can use fetch inside a useEffect, the web industry uses TanStack Query. It handles caching, background refreshing, and loading/error states automatically. It's often paired with Axios or standard Fetch API.

3. Meta-Frameworks: Next.js (CRITICAL)

Vite (what you are using now) is a client-side renderer. This means SEO is bad initially because the HTML is empty until JavaScript runs. Next.js is the massive industry standard right now. It provides Server-Side Rendering (SSR), making pages load instantly with full HTML content for Google to read.

💡 Goal: Once you finish this Vite portfolio, try building a Next.js App Router project.

4. Security and SEO

On mobile apps, SEO doesn't exist and you don't worry about CORS policies. On the web, you'll need to learn how to write Semantic HTML (using tags like <nav>, <section>, <footer> instead of just <div>) for Google Search and Screen Readers, as well as handling HTTP Cookies for authenticated sessions.
